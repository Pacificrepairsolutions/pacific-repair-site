# Pacific Repair — website & customer app

Appliance repair, heating & air conditioning and electrical service in Greater Sacramento and the Central Valley.

- `index.html` — main website (booking wizard, services, service area, brands, reviews, FAQ)
- `app.html` — customer app (installable PWA): bookings, my appliances, maintenance reminders, invoices
- `install.html` — install the app on iPhone, Android or computer
- `appliance-repair-*.html` — service-area pages for local SEO
- `content.js` — all editable text, phones, hours, service areas, brands, licenses, booking email
- `photos/` — own photos (`hero.jpg`, `team-1.jpg`, `work-1.jpg`…) and brand logos (`photos/brands/`)

Static site: no build step. Publish the folder as-is (Netlify, GitHub Pages or any static host).
